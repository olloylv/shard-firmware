**Unofficial custom firmware for the Erica Synths LXR Eurorack module. Not made, approved or supported by Erica Synths. Install at your own risk; the original firmware can be restored at any time.**

SHARD keeps the LXR panel and workflow and lets you put any of 23 sound engines on any of the six channels: LXR classics, Plaits percussion and physical models, Machinedrum-inspired engines and IDM/glitch engines.

### New in 0.4

- CV matrix: 6 slots per channel (36 in total)
- Glitch FX (`glt`): trigger-driven beat repeat instead of the ring modulator
- Screensaver fixes: more timeouts, pot jitter ignored, `idl` diagnostics
- Factory bank 0.5: 128 new kits, grouped by engine family, mixed against the kick, every kit in a key

Full list: [CHANGELOG.md](https://github.com/OWNER/REPO/blob/shard/CHANGELOG.md)

### Install

1. Copy `LXRE_SHARD_V0.4.img` to the root of a FAT32 SD card (remove other `LXRE*.img` files) and the `shard` folder from the bank zip to the root as well.
2. Power off, insert the card, hold the encoder, power on; keep holding until "LXR Updater" appears.
3. Wait for "Update OK!". The start-up screen shows `SHARD v0.4`.

Already on SHARD: global menu → **Upd** → pick the file → confirm.

Back to stock: put the official `LXRE*.img` from Erica Synths on the card and use the bootloader the same way.

Manual: [docs/MANUAL.md](https://github.com/OWNER/REPO/blob/shard/docs/MANUAL.md)
