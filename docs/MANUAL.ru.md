# SHARD — альтернативная прошивка для LXR Eurorack

*Руководство для версии 0.4 и заводского банка 0.5. [English version](MANUAL.md).*

**Неофициальная** прошивка на основе открытого кода LXR (GPL-3.0). Erica Synths её не выпускает и не поддерживает.

Управление и интерфейс остались прежними. Заменены звуковые движки: на каждый из шести каналов можно поставить любой движок.

## Каналы

- 6 одинаковых каналов. Триггеры T1–T6 запускают каналы 1–6.
- Триггер T7 (бывший Open HH) — альтернативный триггер канала 6:
  - хэты (pHH, tHH) открываются;
  - у остальных движков используется **AEG → DcA** (Decay Alt) вместо Decay.
- Кнопки 1–6 выбирают канал, кнопка 7 тоже открывает канал 6.

Подстраницы канала:

| Кнопка | Параметры |
|---|---|
| OSC | **Eng** (движок), Tun (нота), Fin (±64 цента), параметры движка 1–5 |
| MOD / FM / SMP | параметры движка 6–29. Имена берутся у движка; пустые слоты не выбираются |
| AEG | Atk, Dec, Slp, Rep (клап-ретриггер для любого движка), DcA, Vel (velocity → громкость), Mod (AD / off) |
| FLT | Frq, Res, Typ (off/LP/HP/BP/UBP/Nch/Pk/LP2), Drv |
| MIX | Vol, Pan, SR (sample rate), Drv, Out, **Bit** (бит-крашер) |
| LFO | Frq, Ofs, Wav, Rtg (ретриггер от канала 1–6) |

Цепочка обработки канала: **движок → фильтр → AEG → velocity → drive → громкость → SR → Bit → панорама и выход**. У движков с собственной огибающей (все Plaits-ударные, tBD/tSD/tCP/tHH, EFM, Zap, Crs) режим AEG по умолчанию выключен (`Mod = off`), и звук определяет внутренняя огибающая движка.

Drive фильтра задаёт и входное усиление фильтра: 0 — около −8 дБ, 40 — без изменения уровня.

Если сменить движок с панели, загружаются его значения по умолчанию. При загрузке кита сохранённые параметры остаются как есть.

### Входы акцентов

Входы акцентов читаются как гейты: если на входе акцента высокий уровень в момент триггера канала, удар звучит с полной velocity, иначе — с половинной. Акценты также доступны как источники модуляции (см. ниже).

### Режим MOD (CV-матрица)

На каждый канал **6 слотов** (всего 36): источник, глубина, назначение. Источники: CV1–5, LFO1–6, акценты 1–6. В режиме MOD энкодер листает подстраницы канала: слоты 1–2, 3–4, 5–6, затем LFO канала. В новом ките слоты 1–5 уже смотрят на CV1–CV5, слот 6 — на LFO своего канала; остаётся выбрать назначение и глубину.

Киты старых версий загружаются как есть: их три слота становятся слотами 1–3, слоты 4–6 пустые.

Список назначений начинается с общих параметров:

| На LCD | Что модулируется |
|---|---|
| `Mrp` | глубина морфа |
| `Mtg` | кит-цель морфа (±127 китов) |
| `Msh` | резкость морфа |
| `Fwt` | FX dry/wet |
| `Fx1`–`Fx4` | параметры P1–P4 текущего эффекта |

Дальше идут параметры каналов: `VO` (питч 1 В/окт), параметры движка и общая цепочка (Atk, Dec, Slp, Frq, Res, Drv фильтра, Vol, Pan, SR, Drv, Bit, частота LFO). На LCD назначение выглядит как `3sw`: номер канала и сокращённое имя. В режиме редактирования видно полное имя, например `C3 tBD  SweepDec`.

Пустые слоты движка при прокрутке пропускаются. Если назначение указывает на слот, которого у нового движка нет, на экране будет `3--` / `(unused)`.

При глубине 100 % `VO` использует калибровку и квантизацию по полутонам от LXR.

### Морфинг (PERF)

Четыре ручки на экране PERF:

| Ручка | Что делает |
|---|---|
| `Mrp` | глубина морфа 0–255 |
| `Mtg` | кит-цель |
| `Alg` | алгоритм морфа |
| `Shp` | резкость, 0–127 |

Алгоритмы:

- `lin` — линейный. Shp > 0 уводит параметры **дальше** цели (до 2× разницы): в конце хода морф утрирует то, чем кит-цель отличается.
- `snp` — S-кривая вокруг середины. Чем больше Shp, тем уже переход; на 127 кит перескакивает почти сразу. По умолчанию: `snp`, Shp 48.
- `sct` — scatter: у каждого параметра своя точка переключения между 12 и 88 % хода. При большом Shp параметры перескакивают по одному, получается ступенчатый, «рваный» морф.
- `stp` — ход морфа квантуется: Shp 0 = 16 ступеней, Shp 127 = 2 ступени (A/B-переключатель).

Списковые параметры (типы, формы волн, движок) переключаются там, где их кривая проходит середину. Выход канала (Out) не морфится. Морф действует и на FX: P1–P4 и dry/wet плавно, тип эффекта и прочие переключатели — по той же кривой.

Mrp, Mtg и Shp можно модулировать из CV-матрицы (см. выше). «Save morph» сохраняет кит с той же кривой.

Код Plaits взят из репозитория Mutable Instruments (MIT) почти без изменений; поправлена только частота дискретизации. Движки MD-style — собственный код на основе опубликованных описаний машин Elektron Machinedrum; код Elektron не использовался, к Elektron SHARD отношения не имеет.

## Заводской банк

Заводской банк 0.5 — 128 китов, сгруппированных по семейству движков, которое в ките доминирует (не меньше 4 каналов из 6):

| Слоты | Группа | Движки |
|---|---|---|
| 0–31 | `MD…` | tBD tSD tCP tHH EFM GND |
| 32–63 | `PL…` | aBD sBD aSD sSD pHH Mdl Str Prt |
| 64–111 | `ID…` | Zap Crs Byt Rng Cmb — самая безумная часть |
| 112–127 | `HY…` | гибриды, свободная смесь MD/PL/ID |

Исходные голоса LXR (Drm, Snr, Cym, Hat) остаются движками, но в заводском банке не используются.

Роли каналов везде одинаковые: 1 бочка, 2 перкуссия/том, 3 FX (металл, зап, глитч), 4 малый, 5 клап, 6 закрытый хэт, T7 — открытый хэт на канале 6.

### Установка банка

1. Распакуй `shard_bank_v0.5.zip`.
2. Скопируй папку `shard` в корень SD-карты. Если папка `shard` на карте уже есть, киты в `shard/prj00` заменятся; свои киты сначала сохрани отдельно.
3. Загружай киты как обычно (LOAD). Папка `demo/` в архиве — короткие демо каждого четвёртого кита, на карту её копировать не нужно.

### Как собирается банк

Банк генерирует `tools/kits/make_kits.py`:

1. **Пулы голосов.** Для каждой группы и роли есть набор архетипов: параметры заданы в секундах, полутонах и герцах и пересчитываются в значения движка. Каждый архетип рендерится много раз со случайными вариациями внутри своих диапазонов, каждый вариант измеряется одиночным ударом (`tools/kits/analyse.py`): длина, ВЧ-хвост, свист, энергия по полосам, центроид, атака, громкость (K-взвешенная, самые громкие 100 мс), пик-фактор, высота тона. Оценка роли оставляет только то, что встаёт на своё место в миксе: бочка — суб и низ с быстрой атакой, хэты — выше 5 кГц без низкой середины, малый — тело плюс шум без «воздуха» сверху и т.д. Слишком тихие и слишком «пиковые» голоса отбрасываются.
2. **Кит.** Голоса берутся из пула своей группы (до двух гостей), кит получает тему (темп, грув, FX, подвижность) и тональность: звуки с выраженной высотой перестраиваются в ноты лада (бочка — на тонику, том — тоника/квинта, FX — ступени лада). Сведение: громкость одиночного удара каждой роли относительно бочки, high-pass на всём, кроме бочки, драйв канала как мягкий клиппер для пиковых шумовых звуков, стерео-картина (бочка и малый в центре, перкуссия и FX разведены в стороны).
3. **Детализация.** S&H-LFO на тембр FX-канала (каждый удар чуть другой), движение панорамы FX, акценты открывают HP хэтов, акцент на драйв малого, лёгкий S&H на тембр перкуссии; в теме fracture/micro и группе ID — краш, рачеты и случайные ступени высоты. Медленные LFO на параметрах FX-шины. Дилей подбирается под темп кита.
4. **Проверка и мастер.** Кит ещё раз проверяется одиночными ударами (со всей модуляцией), всё звенящее и свистящее укорачивается. В груве ни один канал не громче своей нормы относительно бочки. Уровень кита задаётся громкостью удара бочки (все киты сбалансированы относительно неё), пики грува — не выше −0,6 дБ, без клиппинга.

```sh
cmake -S tools/host -B build/host && cmake --build build/host
python3 tools/kits/make_kits.py build/host/shard_render out/   # out/shard/prj00/*.snd -> в корень SD
```

## SD-карта

Киты, проекты и глобальные настройки SHARD лежат в отдельной папке `/shard` и не пересекаются с китами LXR. Если слот пуст, в нём создаётся init-кит SHARD.

Номер версии формата кита хранится в параметре 0 (`SH_KIT_VERSION`).

## Обновление прошивки

**Из меню (начиная с SHARD 0.1):**

1. Скопируй `LXRE_SHARD_V<версия>.img` в корень SD-карты.
2. Открой глобальное меню (SHIFT + SAVE/LOAD), подстраница 1, пункт **Upd**, нажми энкодер.
3. Выбери файл энкодером, нажми, затем нажми ещё раз для подтверждения.

Прошивка проверяет заголовок и контрольную сумму и пишет образ во вторую половину флеша (секторы 6–7). Затем она проверяет записанное ещё раз и только после этого из ITCM переписывает рабочую область (секторы 1–5) и перезагружает модуль. Загрузчик в секторе 0 не затрагивается. Если перед установкой что-то не так, прошивка показывает ошибку и продолжает работать.

**Аварийный путь:** как в оригинале. При включении держи энкодер, пока не появится «LXR Updater»; загрузчик сам прошьёт `LXRE*.img`. Этот путь работает, даже если питание пропало во время обновления из меню.

Ограничение: размер прошивки до 480 КБ. Образ версии 0.4 занимает около 290 КБ.

## FX: glitch вместо ring mod

Тип эффекта `glt` (на месте бывшего `rng`) — beat repeat, который срабатывает от ударов каналов, отправленных в FX (Out = FX). С вероятностью Chance удар запускает событие: следующий кусок длиной Len записывается и проигрывается насквозь, затем этот кусок заменяет вход и повторяется Rep раз одним из действий: повтор, реверс, октава вниз, октава вверх, рачет (каждый повтор вдвое короче), остановка ленты, случайные ступени высоты. Variety 0 — только повтор, каждый шаг вверх добавляет следующее действие.

| Ручка | Параметр |
|---|---|
| `len` (P1) | длина куска 15–300 мс |
| `chc` (P2) | вероятность на удар |
| `var` (P3) | набор действий |
| `rep` (P4) | число повторов 1–8 |

Глитч использует буфер дилея (одновременно работает только один эффект).

## Скринсейвер

Глобальное меню, пункт `ssv`: off / 2m / 5m / 30s / 10s (время без касания органов управления; по умолчанию 2m). Показывает шесть вертикальных индикаторов уровня каналов на обе строки LCD; группа индикаторов медленно сдвигается, чтобы не выжигать экран. Любая кнопка, энкодер или поворот ручки на 2+ шага возвращает меню; одиночный шаг (дрожание бесконечного потенциометра) таймер не сбрасывает.

Пункт `idl` на глобальной странице показывает время простоя в секундах и последнее касание, сбросившее таймер (b — кнопка, p — ручка, e — энкодер, плюс номер). Помогает, если скринсейвер не включается.

## Загрузка CPU

Глобальное меню → **CPU**: пиковая загрузка аудиоблока в процентах (значение обновляется при перерисовке экрана).

Оценка по количеству инструкций: обычный движок вместе с канальной цепочкой примерно на уровне исходного LXR Drum. Mdl и Prt примерно в 3 раза тяжелее.

## Сборка

```sh
cmake --preset release && cmake --build --preset release      # build/release/LXRE_SHARD_V<версия>.img
cmake -S tools/host -B build/host && cmake --build build/host  # десктопный рендер движков
build/host/shard_render out/                                    # WAV каждого движка + demo_loop.wav
```

Для прошивки нужен Arm GNU Toolchain с C++ (`arm-none-eabi-g++`). В официальном тулчейне Arm он есть.

Чтобы добавить движок:

1. Класс-наследник `shard::Engine` с методами `Init()` и `Render()`.
2. Описание параметров `ShEngineInfo kInfo<Имя>`.
3. `SH_DEFINE_ENGINE_FACTORY(<Имя>)`.
4. Добавить имя в конец `SH_ENGINE_LIST`.
